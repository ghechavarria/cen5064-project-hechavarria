# ADR-006: Google Books as a second book source

**Date:** 2026-10-10
**Status:** accepted (amends ADR-003)

## Context

Open Library alone often has the wrong or a missing cover for a specific printing (for example ISBN 9781503215153 shows a placeholder cover, while Google Books has the real one). The owner wants the app to match the exact copy they hold: publisher, binding and cover.

## Decision

Look up every ISBN in Google Books (official Books API, free key in `EXPO_PUBLIC_GOOGLE_BOOKS_KEY`) and Open Library together. When the Books API has no volume or no cover for the ISBN, Google's cover-by-ISBN image is offered instead (it covers many reprints the search doesn't list; a JPEG is a real cover, a PNG is Google's "no image" placeholder). `MergedIsbnLookup` merges them field by field, edition data first, and keeps every distinct cover as a candidate so the owner can pick theirs or photograph their own. Without a key the app uses Open Library only.

## Consequences

- A second external system appears on the C4 Context diagram.
- The key ships inside the app bundle (normal for client keys); restrict it to the Books API in Google Cloud.
- No scraping (ADR-004 still holds): only the official API is used.

# ADR-004: No bookstore scraping

**Date:** 2026-09-21
**Status:** accepted (supersedes the HTML price-catalog decision)

## Context

The original want-list scraped bookstore HTML. The instructor asked to drop it: the brief allows one optional integration, scrapers break before demos, and commercial sites raise terms-of-service issues.

## Decision

Do not scrape. Do not call price APIs. Wanted is only a shelf. Acquisition (purchased or gifted) is a Domain rule, not a live price.

## Consequences

The only outbound HTTP is Open Library. We lose live “what does this cost today?” The want-list refresh use case is gone.

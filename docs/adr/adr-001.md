# ADR-001: TypeScript + Expo Go modular monolith

**Date:** 2026-09-21
**Status:** accepted

## Context

The instructor required a stated platform that a partner can clone and run without assuming a Mac. A native iOS binary would need Xcode. Flask-in-a-browser was clone-friendly but did not match “mobile app” as closely as Expo Go. The course still requires a 4-tier C4 story in the README.

## Decision

Build one Expo Go app in TypeScript with packages `presentation/`, `service/`, `domain/`, and `data/`. iOS and Android run through the free Expo Go client. Expo web is the conference fallback. Open Library is the only external HTTP adapter.

## Consequences

Yousuf does not need a Mac or a paid developer account. Conference day is `npm install` and `npx expo start`. We give up a Flask/Python stack and a shipped store binary. Domain classes stay ordinary TypeScript classes so the UML diagram stays honest.

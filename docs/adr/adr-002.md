# ADR-002: SQLite on device, JSON fallback on web

**Date:** 2026-09-21
**Status:** accepted

## Context

The course allows one data store. Expo Go has no Postgres server. Expo web (conference fallback) does not always expose `expo-sqlite` the same way a phone does.

## Decision

`SqliteBookRepository` (`expo-sqlite`) is the Data-tier store on iOS/Android. If SQLite cannot open (web or tests), `JsonBookRepository` / `MemoryBookRepository` implement the same `BookRepository` port.

## Consequences

Phones persist a local SQLite file. Web demos still run. Service and Domain never import Expo SQLite. This is not a second product database — it is one port with two adapters.

# ADR-003: Open Library for ISBN metadata

**Date:** 2026-09-21
**Status:** accepted

## Context

ScanBookUseCase needs title, author, cover, and publisher from an ISBN. The instructor capped the project at one optional external integration. Google Books wants a cloud key. Bookstore scraping was rejected.

## Decision

The Data-tier `OpenLibraryIsbnLookup` calls `openlibrary.org/search.json?isbn=` with no key. Successful lookups are cached. Tests use `FakeIsbnLookup`. Presentation never calls Open Library.

## Consequences

Partners need no API keys. A new ISBN fails if Open Library is down and uncached. That is accepted so we stay at one integration.

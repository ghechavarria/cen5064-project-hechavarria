# ADR-005: Expo Go instead of an app-store binary

**Date:** 2026-09-21
**Status:** accepted

## Context

The approval paragraph is a mobile app. Apple Developer and Google Play accounts cost money. Xcode requires a Mac, which the partner may not have on conference day.

## Decision

Ship an Expo Go app. Install Expo Go from the store for free, scan the QR code from `npx expo start`. Optionally press `w` for Expo web. Do not submit to the App Store this semester.

## Consequences

iOS and Android both work without Xcode or Android Studio. Scan uses the phone camera (`expo-camera` barcode detection) in Presentation. Typed ISBN remains the Expo web / no-permission fallback. Do not add a custom native camera build this semester.
